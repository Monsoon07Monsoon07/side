# EC Sales Automation Demo — 「毎月のExcel・CSV作業を自動化します」サービス デモ一式

ココナラで出品する「毎月のExcel・CSV作業を自動化します」サービスの実演用ポートフォリオです。
面倒な売上CSVの集計・転記・グラフ作成を、Excelの数式・テーブル・グラフだけで自動化するデモを収録しています。

**Python等の実行環境は不要です。Windows + Microsoft Excelがあれば、そのまま開いてご利用いただけます。**

## 何を作ったか

- 架空のアパレルEC（表参道店・新宿店・大阪店・EC）の2026年9月分売上データ（3,000件）を生成
- そのCSVを取り込むと自動集計される Excel ダッシュボード（KPI・ランキング・グラフ付き）を作成
- 「表記ゆれだらけの生データ（Before）」と「整形済みデータ（After）」の比較サンプルを作成
- 全ファイルに対して数式エラー・集計不一致・文字化けが無いことを自動テストで検証

実際のご依頼では、お客様がお使いのCSV形式・集計項目・デザインに合わせてフルカスタマイズしてご提供します。

## EC_Sales_Automation_Demo.xlsx の使い方

1. **README シート** — サービス概要と使い方を掲載
2. **売上データ シート** — 売上CSVを取り込む場所（Excelテーブル化済み・フィルター対応）
3. **ダッシュボード シート** — 売上合計・販売点数・注文数・平均単価・平均値引率・EC比率のKPIと、日別推移／カテゴリ別／店舗別／カラー別／サイズ別のグラフ、売上TOP5商品を1画面で確認
4. **商品別／カテゴリ別／店舗別／カラー別／サイズ別 シート** — 各切り口の自動集計表（SUMIFS等の数式で構成、売上データを差し替えると自動再計算）
5. **日別 シート** — 日次の売上・販売数量推移
6. **ランキング シート** — 売上TOP10商品・BOTTOM10商品

すべての集計値は数式（SUMIFS・SUM・AVERAGE等）で構成されており、「売上データ」シートの内容を入れ替えるだけで全シートが自動的に再計算されます。ハードコードされた集計値はありません。

## デザインの方向性

白背景をベースに、濃いグリーン／薄いグリーン／ダークグレーを基調とした、Excel標準の飾り気のない表とは一線を画す清潔感のあるデザインです。タイトル・見出し・KPIカード・表・グラフの階層を明確にし、派手になりすぎない範囲で「プロが作った集計ツール」に見えるよう仕上げています。

## 重要な注意事項

- **このデータはすべて架空のサンプルデータです。** 実在する企業・ブランド・店舗・顧客とは一切関係ありません。
- 数式エラー（#REF!、#VALUE!、#DIV/0!、#N/A等）が無いことを確認済みです（詳細は `TEST_REPORT.md` を参照）。
- Excelを開く際に警告・修復ダイアログが出ないことを、LibreOffice Calcによる再計算・再保存・PDF変換で確認済みです。
- 日本語（全角文字・Excelテーブル名等）を含みますが、文字化けは発生しません。
