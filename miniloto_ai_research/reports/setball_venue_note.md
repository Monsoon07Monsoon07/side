**Status: NOT OBTAINABLE in this session — excluded from the model, not fabricated.**

Set-ball (A〜J) identity per draw and drawing-venue history are not published
by the operator in machine-readable form, and every third-party site that
compiles them (blog.umasaku.com, kujitonari.net, tatuo.net, lotodb.com,
hpfree.com, miniloto.jp, etc.) is outside the small allow-listed set of
domains this sandboxed session can reach (GitHub + standard package
registries only — see reports/data_audit.md for the full list of blocked
hosts). No GitHub-hosted machine-readable mirror of set-ball or venue history
was found via web search either.

Per the task's explicit rule against fabricating, guessing, or interpolating
data when acquisition fails, this project does **not** include any set-ball
or venue features, and the "set-ball-known model" vs "set-ball-unknown
model" split called for in Step 16 is moot — every model in this project is
implicitly a "set-ball-unknown" model. This is a scope limitation of the
available data access, not a finding about set balls.
